# License Inventory

- AL Studio source and starter SVG assets: Apache-2.0 (project release intent;
  add the repository `LICENSE` file before public publication).
- Kokoro model/package: Apache-2.0; verify the installed release notices when
  distributing.
- FFmpeg: LGPL/GPL obligations depend on the installed build and codecs; do
  not redistribute its binaries without reviewing that build's license.
- PyTorch, NumPy, SoundFile, and transitive dependencies retain their own
  licenses. A release must generate and ship a dependency notice inventory.
